# 第1周日计划（功能复现 · Java后端）

目标：跳过已熟悉的分层概念，直接按功能复现核心后端能力，并用测试固化。

执行方式：每天 90 分钟左右，按“复现 50% + 测试 40% + 复盘 10%”推进。
