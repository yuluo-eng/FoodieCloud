# 仓库内 Markdown 文件索引

说明：本表按**路径**列出当前仓库中所有 `.md` 文件（约 20 个）及用途，便于检索与答辩引用。已合并或删除的历史文件名在正文中注明。

| 路径 | 说明 |
|------|------|
| `README.md` | 项目首页：毕设目标、功能范围、快速开始、链接到 `docs/后端接口文档.md` 等 |
| `贡献指南.md` | 参与贡献时的约定与流程（若个人项目可仅作规范备份） |
| `.github/pull_request_template.md` | GitHub PR 描述模板 |
| `docs/development-documentation.md` | **开发总览**：四端、技术栈、功能基线、文档索引 |
| `docs/文档导航.md` | **文档入口导航**：链向必读文档与各专题 |
| `docs/文档索引说明.md` | **本文**：全部 md 文件一览 |
| `docs/development-log.md` | 分批次开发日志（库存、鉴权、审计、测试等） |
| `docs/checklist.md` | 联调与上线前**功能验收清单**（勾选） |
| `docs/testing-guide.md` | **测试方案**：黑盒/白盒、矩阵；**第 7 节**为 MVP 回归用例表（原 `e2e-test-report.md` 已并入） |
| `docs/deploy-guide.md` | 部署与环境变量、构建、发布与回滚 |
| `docs/后端接口文档.md` | **唯一权威 REST API 说明**（原 `backend-api.md` 已合并于此） |
| `docs/研发流程与规范.md` | 研发流程与协作规范 |
| `docs/需求分析模板.md` | 需求分析文档模板（新开需求时可复制） |
| `docs/架构决策记录模板.md` | ADR 模板 |
| `docs/PR1-回顾与操作记录.md` | PR1 阶段回顾与操作记录（历史） |
| `docs/骑手端联调回归记录.md` | 骑手端联调专项记录（历史/追溯） |
| `frontend/前端说明.md` | 前端目录结构、启动命令、代理与构建说明 |
| `thesis/first draft.md` | 论文草稿（事实来源引用 `docs/后端接口文档.md` 等） |
| `thesis/项目进展记录.md` | 论文相关进展记录 |
| `thesis/答辩问题清单.md` | 答辩常见问题备忘 |
