# 联调验收清单

本文档按用户故事列出所有需要验证的端到端场景。验收通过请在对应项前打 ✅。

---

## 1. 用户端

### 1.1 注册 & 登录
- [ ] 用户注册成功后跳转登录页
- [ ] 用户登录成功后跳转点餐首页
- [ ] 已登录用户访问 `/user/login` 自动跳转首页
- [ ] 刷新页面后登录态不丢失
- [ ] Token 过期后自动跳转登录页

### 1.2 个人资料
- [ ] 查看个人资料页（昵称、头像、收货地址）
- [ ] 修改昵称 / 手机 / 收货地址后保存成功
- [ ] 上传头像（≤ 2MB, jpg/png/gif/webp）
- [ ] 上传非法文件（.exe、超大文件）提示错误

### 1.3 点餐 & 购物车
- [ ] 分类列表正常加载，切换分类显示对应菜品
- [ ] 菜品只显示已上架（status=1）的
- [ ] 添加菜品到购物车，购物车角标更新
- [ ] 购物车中修改数量（+/-）
- [ ] 全选 / 取消全选
- [ ] 清空购物车
- [ ] 删除单个购物车项

### 1.4 下单 & 支付
- [ ] 点击结算后生成订单，购物车清空
- [ ] 订单列表显示新订单（待支付状态）
- [ ] 创建支付单成功，Toast 提示支付单号
- [ ] 模拟支付成功后订单变为"已支付"
- [ ] 查询支付状态返回正确文案
- [ ] 库存不足时支付失败，订单不变更
- [ ] 取消未支付订单成功

### 1.5 订单详情
- [ ] 展开订单明细显示菜品名、单价、数量
- [ ] 收起明细后再展开不重复请求

- [ ] 刷新页面后登录态不丢失
- [ ] 已登录访问 `/merchant/login` 自动跳转首页

### 2.2 店铺设置
- [ ] 查看 / 修改店铺名称、地址、电话、公告
- [ ] 切换营业状态（营业中 ↔ 已打烊）
- [ ] 保存后 Toast 提示成功

### 2.3 分类管理
- [ ] 新增分类（名称 + 排序 + 状态）
- [ ] 编辑当前选中分类
- [ ] 删除空分类成功
- [ ] 删除有菜品的分类提示失败

### 2.4 菜品管理
- [ ] 新增菜品（含图片上传）
- [ ] 编辑菜品，更换图片后旧图片被清理
- [ ] 上下架切换
- [ ] 删除菜品

### 2.5 订单管理
- [ ] 订单列表加载（支持状态筛选）
- [ ] 查看订单详情（明细列表）

### 2.6 上传安全
