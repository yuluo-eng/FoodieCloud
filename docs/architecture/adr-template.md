## 背景（Context）

描述当前问题、约束条件、技术与业务背景。

示例：

- 系统并发增长，当前同步调用导致响应时间波动。
- 需要在不显著增加复杂度的前提下提升稳定性。

## 决策（Decision）

明确本次采用的方案与边界。

示例：

- 引入异步消息队列处理非核心链路。
- 保持核心交易链路同步，确保一致性。
