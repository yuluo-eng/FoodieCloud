# 悦食汇前端说明（Vue 3 + Vite）

## 启动方式

1. 先启动后端（默认 `http://127.0.0.1:8080`）
2. 在本目录执行：

```bash
npm install
npm run dev
```

开发地址一般为：`http://127.0.0.1:5173`

## 页面路由

- `/`：首页（角色入口）
- `/user/login`、`/user/register`、`/user`
- `/merchant/login`、`/merchant`
- `/rider/login`、`/rider`

## 构建

```bash
npm run build
npm run preview
```
