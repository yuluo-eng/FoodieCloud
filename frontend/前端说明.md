# 悦食汇前端说明（Vue 3 + Vite）

## 启动方式

1. 先启动后端（默认 `http://127.0.0.1:8080`）
2. 在本目录执行：

```bash
npm install
npm run dev
```

开发地址一般为：`http://127.0.0.1:5173`

## 页面路由

- `/`：首页（角色入口）
- `/user/login`、`/user/register`、`/user`
- `/merchant/login`、`/merchant`
- `/rider/login`、`/rider`
- `/admin/login`、`/admin`：管理后台（需 **SUPER_ADMIN** 员工账号）；「商家管理」Tab 内可进行 **平台代入驻**：新建店铺、为指定店铺创建店长账号（调用 `/api/admin/shops`、`/api/admin/shops/{shopId}/employees/bootstrap`，详见根目录 `docs/后端接口文档.md` §10）

## 构建

```bash
npm run build
npm run preview
```
